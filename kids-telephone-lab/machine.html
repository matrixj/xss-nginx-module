🔌 电路框图

各模块怎么接（基础版，免焊接）

模块接法
话筒 → 功放驻极体话筒模块（带放大板）OUT → 功放 IN；共地
功放 → 喇叭功放 OUT+ / OUT− → 8Ω 喇叭两线
按讲键 PTT串联在话筒供电线上：按下才送话（防啸叫、像真对讲机）
电源4×AA 电池盒 → 总开关 → 两块功放 VCC/GND
长线双芯线 3–10 米：一芯音频、一芯地。两端用 3.5mm 插头/插座对接，方便收纳
呼叫铃A 端按钮 → 主机有源蜂鸣器（5V）→ 电源
插孔灯每个插孔旁 LED + 220Ω 电阻；插头插入压下微动开关即点亮
免焊接三件套：杜邦线、按压式接线端子、面包板。需要更牢固时请家长用电烙铁（升级版）。

📦 外壳制作（孩子参与度最高的部分）

  1. 主机：鞋盒大小的纸盒或 30×20×10cm 木盒。家长开好插孔圆孔和开关孔。
  2. 孩子任务：给主机涂色、写名字（「××电话局」）；画 4–6 个地点小卡片贴在插孔旁；贴四个时代贴纸（绳子 → 电线 → 接线生 → 手机）。
  3. 听筒：两个纸杯或圆形塑料盒做外壳，喇叭和话筒用热熔胶固定（家长操作），手柄用粗纸筒。孩子装饰成「老电话」样子。
  4. 插头线：3.5mm 插头接双芯线，线尾挂一个木珠当「接线生的手」。

🪜 调试顺序（每步都让孩子在场看）

  1. 单听筒：话筒 → 功放 → 喇叭，对着话筒吹气，喇叭有声。
  2. 双听筒直连：A 说 B 听，反过来再试。
  3. 加按讲键：不按没声，按了有声。
  4. 加长线：拉到走廊尽头再试。
  5. 加呼叫铃：按铃，主机响。
  6. 加交换台：插孔灯亮，通话正常。
  7. 总装外壳，孩子验收：「××电话局正式开业！」
💡 每步失败都只查当前这一步新增的线，不要全拆。

🔽 简化与降级方案

如果就
不想做交换台只做实验 6 的一对一对讲，用鞋盒挖孔当「电话局」装饰
没有微动开关插孔灯改成「插入后由家长拨一个小开关」，仪式感十足即可
买不到功放套件用两块 LM386 成品功放板（约 3–5 元/块），自带电位器
没有 3.5mm 插头长线两端用按压接线端子直连，牺牲可插拔
孩子才 5–6 岁只做纸杯电话 + 电磁听筒 + 观察旧电话，机器由家长做好给孩子玩
🔧 升级版（可选，需要焊接）

• 加听筒 C：交换台插孔分别接 B/C，实现真正「打给不同的人」。

• 用继电器做插孔自动切换，插入即断开其他路。

• 加一块「拨号盘脉冲 → LED 闪烁」演示板，展示拨号盘时代（纯演示，不接电信网）。

• 录音模块（ISD1820）做「留言电话」：没人接就留言。
