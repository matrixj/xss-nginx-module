# 小小接线生 · 电话课题实验室

给 **7 岁小朋友** 的儿童级课题研究方案。孩子喜欢电话机，我们就用电话把「历史故事」和「动手实验」绑在一起：先听懂声音怎么跑，再亲手做出一台能通话的机器。

目标不是背发明年代，而是让孩子像小科学家一样：**提问 → 猜想 → 动手试 → 记录 → 讲给别人听**。

## 推荐路径（最少准备也能开始）

1. **本周就能做**：纸杯电话 + 米粒看振动（家里现有材料即可）。
2. **两周内做出机器**：按基础版采购（大约 80–150 元），拼出双向对讲听筒。
3. **完整课题**：加上交换台、旧电话观察、时间线墙和结题小报告。

三档预算见 [05-采购清单.md](05-采购清单.md)。没有电烙铁也能做完整课题；焊接只出现在「升级版」。

## 安全红线（请先看）

- 只用 **电池（3–4.5V）**，不要接 220V 市电。
- 旧式拨号电话可以观察、把玩外形，**不要插家里的电话墙插**，铃流电压很高。
- 磁铁用大号的，收进盒子，避免误吞。
- 戳洞、剪线、剥线由家长做；孩子负责装饰、接线、实验、记录。

## 科学上我们真正在学什么

孩子看到的是「打电话」。底下藏着四件小学就能摸到的科学：

1. **声音是振动**（声波电话）
2. **振动可以沿着绳子/空气跑**（介质）
3. **电路接通，东西才会工作**（交换台插线）
4. **电和磁可以互相帮忙，把声音变成电，再变回声音**（电磁听筒）

历史部分用来回答：「人们为什么要发明这个？以前的人怎么解决同样的问题？」这样科学和技术就不会变成干巴巴的零件。
