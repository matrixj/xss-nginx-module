# 家长指南：怎么陪，孩子才真的在「研究」

这份指南比任何物料都重要。同一套实验，陪法不同，孩子得到的完全不同。

---

## 1. 三条总原则

1. **孩子动手，家长动嘴。** 戳洞、焊接、剥线是家长的；猜想、接线、装饰、记录、演示是孩子的。
2. **先猜想，后动手。** 每次实验前问一句「你觉得会怎样？」猜错了更值钱——那是孩子自己的发现时刻。
3. **失败是数据。** 线松了听不见，不是「做错了」，是「发现了线要拉直」。请说：「科学家也经常第一次不成功。」

---

## 2. 提问话术（替换掉「你看懂了吗」）

| 场景 | 别问 | 改问 |
| --- | --- | --- |
| 实验前 | 「知道今天要学什么吗」 | 「你猜米会不会跳？为什么？」 |
| 现象出现 | 「看到了吧，这就是振动」 | 「你看到了什么？和刚才猜的一样吗？」 |
| 失败 | 「我来弄」 | 「我们可以换哪一样东西再试一次？」 |
| 结束后 | 「记住了吗」 | 「如果给爷爷讲，你会怎么说？」 |
| 孩子提问 | 直接给答案 | 「这个问题好，我们怎么试才能知道？」 |

孩子答不出时，等 5 秒。沉默比标准答案珍贵。

---

## 3. 每周观察记录（家长私下填，不给孩子压力）

每周结束后花 2 分钟打勾：

| 观察点 | 第1周 | 第2周 | 第3周 | 第4周 | 第5周 | 第6周 |
| --- | --- | --- | --- | --- | --- | --- |
| 主动提出问题 | | | | | | |
| 实验前说出猜想 | | | | | | |
| 愿意再试一次（失败后） | | | | | | |
| 能用「因为…所以…」说一个发现 | | | | | | |
| 主动想给别人演示 | | | | | | |

连续两周同一项空白，就在下一周特意创造机会（例如故意把线放松，等他发现）。**不要**把这张表给孩子看或打分。

---

## 4. 兴趣保护清单

- 单次不超过 40 分钟，孩子说「不想做了」就停，收在「明天继续」的悬念里。
- 六周里至少有一次完全由孩子决定「今天试什么」。
- 把作品放在家里显眼处，客人来了让孩子演示——被需要是最好的燃料。
- 不和别人家孩子比，不和「标准答案」比。
- 孩子的新问题写进「还想研究的事」清单（W6 背面），这就是下一个课题的种子。

---

## 5. 常见坑

| 坑 | 后果 | 解法 |
| --- | --- | --- |
| 家长连夜把机器做完 | 孩子失去所有权 | 哪怕丑，也留一半工序给孩子 |
| 一次讲完电话史 | 孩子只记住「贝尔」两个字 | 六周慢慢讲，每周只讲一段 |
| 追求机器好看 | 变成家长手工比赛 | 目标是「能通话 + 孩子能讲」 |
| 用考试语气验收 | 兴趣熄火 | 用「教教我」代替「考考你」 |
| 电磁听筒没声就放弃 | 错过最酷的一课 | 按实验手册「失败排查表」逐项查，声音本来就轻 |

---

## 6. 如果想更进一步（可选）

- 参观：电信博物馆、科技馆通信展区；出发前让孩子带一个问题去。
- 采访：给爷爷奶奶打电话，问「你小时候怎么打电话？」录下来，放进结题报告。
- 延伸课题种子：电报与摩斯码（第 2 周可埋钩子）、声音的高低（敲不同水杯）、手机为什么没线（留给 8 岁+）。
