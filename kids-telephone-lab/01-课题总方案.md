# 课题总方案：电话从哪里来？

**课题名称**：电话从哪里来？声音是怎么跑到很远的地方的？  
**适合年龄**：6–8 岁（按 7 岁设计）  
**时长**：6 周，每周 1–2 次，每次 25–40 分钟  
**结题形式**：一张时间线海报 + 一台能通话的机器 + 一份孩子口述、家长代写的小报告

---

## 1. 为什么选这个课题

7 岁儿童正处在「具体运算」的入口：他们相信自己看见、摸到、试过的东西，还不爱听抽象讲解。电话机刚好同时满足三件事：

- **兴趣入口**：孩子已经喜欢电话，学习从热爱开始，而不是从课本开始。
- **可动手**：纸杯、绳子、磁铁、电池都能立刻产生现象。
- **有历史**：同一个问题（把声音送到远方）被不同时代用不同办法解决，这就是技术史，也是科学思维。

本方案依据《义务教育科学课程标准》里低年级强调的实践：观察、提问、猜测、简单对比实验、用自己的话解释、乐于交流。不要求公式，不要求背专利号。

---

## 2. 研究大问题（贴在墙上，六周都不换）

> **声音怎么才能跑到很远的地方？**

下面挂 3 个小问题，每周攻克一点：

1. 说话的时候，到底什么在动？
2. 没有电的时候，人们怎么「打电话」？
3. 有了电以后，电话为什么能打得更远？接线生是干什么的？

孩子若自己冒出新问题（「手机为什么没有线？」），记下来，放到第 6 周当「还想研究的事」，不要中途改题。

---

## 3. 科学素养目标（给家长看，不要念给孩子听）

| 素养 | 6 周结束时，孩子大概能做到 |
| --- | --- |
| 提问 | 会问「如果绳子松了会怎样？」这类能动手试的问题 |
| 猜想 | 实验前先说自己的猜测，而不是直接上手 |
| 控制变量 | 知道一次最好只换一样东西（换线、换杯子、换距离） |
| 证据 | 能指着现象说「我看见米粒跳了，所以杯子在振动」 |
| 解释 | 用「因为……所以……」讲给家人听，不一定用科学名词 |
| 技术与社会 | 知道电话是为了解决「人隔得很远还想说话」 |
| 兴趣 | 还想再试、还想给别人演示，而不是「做完任务了」 |

评估用观察，不用打分。记录表在 [06-家长指南.md](06-家长指南.md)。

---

## 4. 六周日程

每次结构固定，孩子会有安全感：

1. 回顾（3 分钟）：上次发现了什么？
2. 故事或问题（5 分钟）
3. 动手（15–20 分钟）
4. 记录与演示（5–8 分钟）：画一画、说一说

### 第 1 周 · 声音会跳舞

- **共读**：[02-给孩子读的电话故事.md](02-给孩子读的电话故事.md) 第 1 章
- **实验**：实验 1 米粒看振动、实验 2 喉咙摸一摸
- **记录**：W1、W2
- **墙上**：贴出大问题

### 第 2 周 · 没有电的电话

- **共读**：第 2 章（纸杯电话的祖先：传声筒）
- **实验**：实验 3 纸杯电话；对比棉线 / 钓鱼线 / 毛线，以及拉直 / 放松
- **记录**：W3
- **科学点**：声音是振动；线要绷紧；捏住线，振动过不去

### 第 3 周 · 电来了，磁也来了

- **共读**：第 3 章（贝尔和「会说话的机器」；轻轻提到很多人一起努力）
- **实验**：实验 4 电磁铁吸回形针；实验 5 纸杯电磁听筒（听见手机里的声音）
- **科学点**：电可以变成磁；磁可以推动杯子振动，振动就是声音
- **注意**：这一周概念最难。成功标准是「听见了、愿意再试」，不是讲清电磁感应。

### 第 4 周 · 做出时光电话机（上）

- **制作**：听筒 A、听筒 B、电池盒、功放模块（家长主导组装，孩子装饰听筒、贴标签）
- **实验**：实验 6 一对一有线对讲
- **游戏**：隔着门通话，体验「远」

### 第 5 周 · 小小接线生（下）

- **共读**：第 4 章（接线生、上海的德律风、电话号码从哪里来）
- **制作**：把交换台插孔和「小房子」装上
- **实验**：实验 7 插线呼叫；实验 8 拆开观察旧电话外形（可选）
- **游戏**：角色扮演「接线生」
- **记录**：W5

### 第 6 周 · 我是小研究员

- **共读**：第 5 章（从拨号盘到手机，只讲变化，不讲基站细节）
- **制作**：时间线海报（W4）
- **结题**：孩子对着机器演示，家长用 W6 代写小报告；打开 [museum.html](museum.html) 一起点一点
- **庆祝**：给机器命名，拍照，打给爷爷奶奶演示纸杯电话或对讲机

若某周失败（听筒没声、孩子累了），把制作拆成两次，宁可慢，不要变成家长的工程作业。

## 5. 知识地图（成人版，对孩子只需口述加粗句）

```text
声音 = 物体在振动
        │
        ├─ 空气里传（平时说话）
        ├─ 绳子里传（纸杯电话）← 第 2 周
        └─ 先变成电，再变回振动（电话）← 第 3–5 周
                    │
                    ├─ 话筒：振动 → 电
                    ├─ 电线：把电送到远方
                    ├─ 听筒：电 → 振动 → 声音
                    └─ 交换机：决定这条电去谁家 ← 接线生
```

历史节点（给海报用，不必一次讲完）：

| 大概年代 | 孩子能懂的说法 |
| --- | --- |
| 很久以前 | 人要跑步、骑马送信 |
| 电报时代 | 用「嘀嘀嗒嗒」的电信号传字，还不能传说话 |
| 1876 年前后 | 贝尔等人做出能传送说话的机器 |
| 1877–1882 | 中国上海出现早期电话（当时叫「德律风」） |
| 接线生时代 | 打电话要有人帮你把线插到对方那里 |
| 拨号盘时代 | 转圈子，机器自己接线 |
| 按键电话 | 嘀嘀嘀，按数字 |
| 大哥大 / 手机 | 线不见了，人可以走动着打 |
| 今天 | 手机还能看图、发消息，但「把声音送到远方」这件事还在 |

发明权在历史上有争议（贝尔、格雷、梅乌奇等）。对 7 岁只说：**很多人都在想办法，贝尔做出了很有名的一台，并得到了专利。** 家长若被追问，可说「科学上常常是许多人一起做成的」。

## 6. 机器在课题里的位置

机器不是奖品，是 **第 4–5 周的实验装置**，也是结题展品。

它要同时完成三件事：

1. **能通**：两边真的能听见说话（科学证据）
2. **能玩**：孩子当接线生插线（历史体验）
3. **能讲**：指着四个时代灯，说出「以前用绳子，后来用电，后来有接线生」

详细图纸见 [04-时光电话机设计.md](04-时光电话机设计.md)。

---

## 7. 结题标准（做到 3 条就算成功）

1. 孩子能演示纸杯电话或时光电话机其中一样，并说一句自己的发现。
2. 墙上有一条孩子参与制作的时间线（可以很稚拙）。
3. 孩子愿意再给一位家人「上课」。

不成功的标志不是机器不好看，而是孩子说「都是爸爸做的」或「我不知道为什么」。若出现这种情况，回到第 2 周纸杯电话，让孩子重新当主角。
