# 「小小接线生 · 时光电话机」设计文档

一台给 7 岁孩子操作的有线对讲 + 人工交换台。孩子插线呼叫，两边真的能通话。全程电池供电，免焊接也能完成。

---

## 1. 它长什么样

```text
        ┌──────────────────────────────────────────────┐
        │              时 光 电 话 机 主 机              │
        │                                              │
        │   [1876 绳] [1882 电] [接线生] [2026 手机]    │  ← 四个时代灯（装饰）
        │      ○        ○        ○         ○          │
        │                                              │
        │   ┌───────┐  ┌───────┐  ┌───────┐  ┌───────┐ │
        │   │ 家    │  │ 学校  │  │ 医院  │  │ 爷爷家│ │  ← 交换台插孔
        │   │  ◉    │  │  ◉    │  │  ◉    │  │  ◉    │ │
        │   └───────┘  └───────┘  └───────┘  └───────┘ │
        │        插头线 ●──────────（接线生的手）        │
        │                                              │
        │   [呼叫铃🔔]        [电源开关] [电池盒 4×AA]   │
        └──────────────────────────────────────────────┘
           │ 长线（3–10 米）                │ 长线
           ▼                                ▼
      ┌──────────┐                    ┌──────────┐
      │ 听筒 A   │                    │ 听筒 B   │
      │ 话筒+喇叭│                    │ 话筒+喇叭│
      │ [按讲键] │                    │ [按讲键] │
      └──────────┘                    └──────────┘
```

- **主机**：纸箱或木盒，正面是交换台（插孔 + 地点标签 + 呼叫铃）。
- **听筒 A/B**：两个一模一样的对讲端，各含驻极体话筒、小喇叭、功放模块、按讲键。
- **交换台**：插头插进哪个孔，A 就连到哪个「地点」。基础版里 B 就是所有地点的化身；升级版可加听筒 C，实现真正的三方选线。

---

## 2. 工作原理（讲给孩子听的版本）

```text
听筒A：说话 → 话筒把振动变成电 → 功放把电变强
              │
        长长的电线（穿过交换台）
              ▼
听筒B：电推动喇叭里的磁铁和线圈 → 纸盆振动 → 听见声音
```

交换台做的事和 100 年前的接线生一样：**决定电走哪条路**。插头 = 接线生的手，插孔 = 各家各户。

## 3. 电路框图

```text
                 ┌──────── 4×AA 电池盒（6V，带开关）────────┐
                 │                                          │
        ┌────────┴─────────┐                      ┌────────┴─────────┐
        │  听筒 A          │                      │  听筒 B          │
        │  驻极体话筒 ─┐   │   音频线（双芯）      │  驻极体话筒 ─┐   │
        │  PTT 按键 ───┤   │ ◄══════════════════► │  PTT 按键 ───┤   │
        │  功放模块 ───┘   │   （经过交换台插孔）   │  功放模块 ───┘   │
        │  8Ω 小喇叭       │                      │  8Ω 小喇叭       │
        └──────────────────┘                      └──────────────────┘

交换台（主机正面）：
  呼叫：A 端按钮 ──► 主机蜂鸣器/铃铛（提示接线生）
  选线：A 的音频线 → 插头 → 插进 [家/学校/医院/爷爷家] 任一插孔
        基础版：所有插孔内部并联到 B（插哪个都通 B，灯亮对应孔）
        升级版：插孔分别接到 B、C 听筒（真选线）
  指示灯：每个插孔配一个 LED + 220Ω 电阻，插入即亮（插头带开关触点或用光敏/微动，见 §6 简化方案）
```

**给 7 岁的简化**：基础版里，插孔只做「灯亮 + 接通 B」两件事，不做真正的多路切换。孩子体验到「插线才能通」就够了。

## 4. 物料与接线（基础版，免焊接）

| 模块 | 接法 |
| --- | --- |
| 话筒 → 功放 | 驻极体话筒模块（带放大板）OUT → 功放 IN；共地 |
| 功放 → 喇叭 | 功放 OUT+ / OUT− → 8Ω 喇叭两线 |
| PTT 按键 | 串联在话筒供电线上：按下才送话（防啸叫、像真对讲机） |
| 电源 | 4×AA 电池盒 → 总开关 → 两块功放 VCC/GND |
| 长线 | 双芯线 3–10 米：一芯音频、一芯地。两端用 3.5mm 插头/插座对接，方便收纳 |
| 呼叫铃 | A 端按钮 → 主机有源蜂鸣器（5V）→ 电源 |
| 插孔灯 | 每个插孔旁 LED + 220Ω 电阻；插头插入压下微动开关（或插孔自带开关触点）即点亮 |

免焊接手段：杜邦线、接线端子（按压式）、面包板短接。需要更牢固时，请家长用电烙铁（升级版）。

---

## 5. 外壳制作（孩子参与度最高的部分）

1. **主机**：鞋盒大小的纸盒或 30×20×10cm 木盒。家长开好插孔圆孔和开关孔。
2. **孩子任务**：
   - 给主机涂色、写名字（「××电话局」）
   - 画 4–6 个地点小卡片贴在插孔旁（家、学校、医院、消防、爷爷家、好朋友）
   - 贴四个时代贴纸：绳子 → 电线 → 接线生 → 手机
3. **听筒**：用两个纸杯或两个圆形塑料盒做外壳，喇叭和话筒用热熔胶固定在里面，手柄用粗纸筒。孩子装饰成「老电话」样子。
4. **插头线**：3.5mm 插头焊/接到双芯线，线尾挂一个木珠当「接线生的手」。

---

## 6. 简化与降级方案

| 如果 | 就 |
| --- | --- |
| 不想做交换台 | 只做实验 6 的一对一对讲，用鞋盒挖孔当「电话局」装饰 |
| 没有微动开关 | 插孔灯改成「插入后由家长拨一个小开关」，仪式感十足即可 |
| 买不到功放套件 | 用两块「LM386 成品功放板」（约 3–5 元/块），自带电位器 |
| 没有 3.5mm 插头 | 长线两端用按压接线端子直连，牺牲可插拔 |
| 孩子才 5–6 岁 | 只做纸杯电话 + 电磁听筒 + 观察旧电话，机器由家长做好给孩子玩 |

---

## 7. 升级版（可选，需要焊接）

- 加听筒 C：交换台插孔分别接 B/C，实现真正「打给不同的人」。
- 用继电器做插孔自动切换，插入即断开其他路。
- 加一块「拨号盘脉冲 → LED 闪烁」演示板，展示拨号盘时代（纯演示，不接电信网）。
- 录音模块（ISD1820）做「留言电话」：没人接就留言。

---

## 8. 调试顺序（每步都让孩子在场看）

1. 单听筒：话筒 → 功放 → 喇叭，对着话筒吹气，喇叭有声。
2. 双听筒直连：A 说 B 听，反过来再试。
3. 加 PTT：不按没声，按了有声。
4. 加长线：拉到走廊尽头再试。
5. 加呼叫铃：按铃，主机响。
6. 加交换台：插孔灯亮，通话正常。
7. 总装外壳，孩子验收：「××电话局正式开业！」

每步失败都只查当前这一步新增的线，不要全拆。
